# Evaluación de Modelos

## Objetivo
Validar el rendimiento de los modelos de Machine Learning desarrollados.

## Actividades Principales
- Validación y pruebas de rendimiento
- Cálculo de métricas: AUC, Precisión, Recall
- Comparación entre modelos

## Entregables / Productos
- Resultados de métricas y validación
